EV 충전 기록(이하 "앱")은 사용자의 개인정보를 소중히 여깁니다.
앱은 별도 서버를 운영하지 않으며, 모든 충전 기록은 기기 내에만 저장됩니다.

1. 수집하는 정보 및 목적

구분수집 정보목적처리 주체
충전 기록 날짜, 충전소명, 충전량(kWh), 금액, 사업자명 앱 기능 제공 (기기 내 로컬 저장) 앱 자체 (서버 전송 없음)
Google Drive 백업 Drive 파일 생성·읽기 권한
(백업 파일만 접근)		 사용자 요청 시 충전 기록 백업·복원 Google LLC
광고 (AdMob) 광고 식별자(GAID), 기기 정보, IP 주소 맞춤형 배너 광고 노출 Google LLC (AdMob)
앱 사용 통계 화면 조회, 버튼 클릭 등 익명 이벤트 앱 품질 개선 (Firebase Analytics) Google LLC (Firebase)
OCR (카메라) 사용자가 직접 촬영한 충전 영수증 이미지 영수증 텍스트 자동 인식 후 즉시 삭제 Google ML Kit (기기 내 처리)

2. 개인정보의 보관 및 파기

  • 충전 기록: 사용자가 직접 삭제하거나 앱을 제거할 때까지 기기 내 보관
  • Google Drive 백업 파일: 사용자가 Drive에서 직접 삭제하기 전까지 보관
  • OCR 이미지: 텍스트 인식 완료 즉시 삭제 (서버 전송 없음)
  • 광고·분석 데이터: Google의 데이터 보존 정책에 따름

3. 제3자 제공 및 위탁

앱은 수집된 정보를 아래 제3자에게 위탁하여 서비스를 제공합니다.

수탁자위탁 내용개인정보처리방침
Google LLC Drive 백업, 광고(AdMob), 분석(Firebase), ML Kit OCR Google 개인정보처리방침

위 경우 외에는 사용자의 동의 없이 개인정보를 제3자에게 제공하지 않습니다.

4. 사용자 권리

  • 기록 삭제: 앱 내 '삭제' 기능 또는 앱 제거로 모든 로컬 데이터 삭제
  • Drive 백업 삭제: Google Drive에서 직접 백업 파일 삭제
  • 광고 개인화 거부: 기기 설정 → Google → 광고 → 광고 개인화 선택 해제
  • Google 계정 연결 해제: 앱 설정에서 Google 로그아웃

6. 아동 개인정보 보호

앱은 만 14세 미만 아동을 대상으로 하지 않으며, 의도적으로 아동의 개인정보를 수집하지 않습니다.

7. 방침 변경 안내

개인정보처리방침이 변경될 경우 앱 업데이트 또는 이 페이지를 통해 공지합니다. 중요한 변경은 앱 내 팝업으로 별도 안내합니다.
